# Протокол встречи: распределение ответственности (проект QA Agent / сокращение регресса)

**Тема:** ретроспектива и фиксация договорённостей по зонам ответственности  
**Формат:** протокол по достигнутым договорённостям  
**Участники:** Степан Панов, Валерий Никаноров, Виктор Челяпин, Денис Невзоров, Ян Елисеев, Виталий Раевский, Николай Козлов  
**Упомянуты / вне встречи:** Лев, Артём, Максим Тавицкий, Вадим Гаалиев, Лёша, Никита

---

## 1. Образ результата (цель)

| Параметр | Договорённость |
|---|---|
| Базовая метрика | Длительность **прогона** регрессионного тестирования |
| Текущее состояние | **~5 дней** при полной утилизации ресурсов тестирования (фактически дольше из‑за утилизации PIO ~30–50%) |
| Целевой результат | Сокращение прогона **с 5 дней до ≤ 1 суток** |
| Идеальный / «жирный» результат | **6–8 часов** прогона (полностью автоматизированный регресс: часть нативных тестов + часть UITars / AI, с распараллеливанием) |
| Неприемлемый результат | Сокращение только до 2–3 дней — **недостаточный** результат |
| Срок | Изначально — **конец текущего года**. Есть сигнал о возможном сдвиге на **конец 1‑го квартала** — **требует подтверждения** |
| Критерий для Льва | Увидеть «1 день против 5» |

**Способ достижения (принципиально):** способ вторичен. Допустима гибридная модель:
- максимум тестов, которые можно покрыть **кодом** — нативные автотесты без LLM;
- то, что невозможно закрыть кодом — агенты / LLM («протыкивание»).

**Риск‑менеджмент** (рискоориентированный подход) — **не в текущей итерации**: включается в следующую итерацию развития агентов после реализации основного сокращения регресса (Виктор Челяпин).

## 5. Формат сотрудничества (перезапуск)

Ранее: модель «вендор решения — заказчик решения».  
**Новый формат:** все совместно дорабатывают решение «кто как может»; зоны разведены, руки пожаты.

Владелец цели «в целом» перед Львом **окончательно не назван одним человеком**; при этом:
- по инструментарию агентов доклад обычно ведёт **Виталий**;
- статус по борду трекает **Валерий**;
- верификацию и прогресс внедрения со стороны тестирования ведёт **Виктор**.

Спрашивать «кто owner цели у Льва» напрямую на общей встрече с Львом — **нежелательно** (риск негатива). Предпочтительнее договориться внутри и при необходимости уточнить точечно.
